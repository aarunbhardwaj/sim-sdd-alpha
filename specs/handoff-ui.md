# Minimal handoff UI

## Status

draft

## Intent

A single page lets a teammate submit the same fields as create and see the recent list from the list API. This stretch task is not required for the core demo.

## Requirements

- REQ-HANDOFF-UI-1 Provide a minimal page that creates a handoff and shows recent rows.

## Acceptance criteria

- AC-HANDOFF-UI-1 A user can submit author, severity, and summary through the page.
- AC-HANDOFF-UI-2 The list view shows rows returned by the list API.

## Out of scope

Authentication, styling systems, and offline support. Skip this task if Tasks 1–3 slip.
