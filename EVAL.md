# Evaluation task scaffold

Candidate task rows for the team repository. An unregistered row is **collected**
when the IDE MCP client calls `practice.register_task` before implementation.
There is no participant-operated Register task control. DSPy does not register
tasks. Blank `task_id` and `arm` cells are placeholders, not evidence and not an
arm choice.
